# Безопасность и конфиденциальность

1. Используйте Google Drive OAuth со scope `drive.readonly`. Не предоставляйте скрипту доступ на запись в источник.
2. Выделите сервисному доступу Seafile только нужную библиотеку; настройте минимальные права.
3. Не коммитьте настоящий `~/.config/rclone/rclone.conf`, OAuth-токены, логины, пароли, файлы состояния или манифесты.
4. `rclone rcd` в исходной v6 использует `--rc-no-auth`, но слушает **только `127.0.0.1` на динамическом порту**. Не перенаправляйте этот порт наружу и не открывайте его на `0.0.0.0`.
5. Исходная папка Google Drive зафиксирована в коде; её идентификатор может раскрывать сведения об источнике. Проверьте перед публичной публикацией.
6. Делайте независимую копию `manifest.json` и `state_v5.json` для восстановления после сбоя, но храните её приватно.
7. Скрипт не удаляет и не перезаписывает целевые объекты автоматически; ручное удаление библиотеки Media или источника не требуется.
8. При публикации репозитория внимательно проверьте `git status` и `git diff --cached` перед `git push`.
